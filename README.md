# КОМПОЗИТ Т.А. — сайт завода

Корпоративный сайт ООО «Композит Т.А.» — единственного производителя
стеклопластиковых (GRP) труб в Республике Таджикистан.

Аудитория — тендерные комиссии международных финансовых институтов
(Всемирный банк, ЕБРР, АБР, ИБР), государственные заказчики и подрядчики.
Отсюда требования: три языка, документы и сертификаты в открытом доступе,
проверяемые цифры по проектам.

- Домен: **composite.tj**
- Демо: **kompozit-ta.vercel.app**

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:3000

```bash
npm run build     # прод-сборка
npm run lint      # eslint
npx tsc --noEmit  # проверка типов
```

**Не запускайте `next build`, пока работает `next dev`.** Оба пишут в `.next`,
и сайт начнёт отдавать 500. Если это случилось: `rm -rf .next` и перезапуск.

## Тексты и языки

Три локали: `ru` (без префикса в адресе), `tj`, `en`.

**Ни одной строки текста в JSX.** Всё через `useTranslations` /
`getTranslations` и файлы `messages/`. Новый ключ добавляется сразу в три файла,
иначе на странице появится `MISSING_MESSAGE`.

Таджикский требует отдельного внимания: Unbounded и JetBrains Mono не рисуют
буквы ӯ ғ қ ҳ ҷ, поэтому для `[data-locale="tj"]` шрифты подменяются на Manrope.
Правило живёт в `globals.css`. Любую правку шрифтов проверять на `/tj`.

Как называть продукт — таблица в `DESIGN.md`, раздел 10. Коротко: в больших
заголовках «композитные трубопроводы», в технических местах «стеклопластиковые
трубы (GRP)», в английской версии везде `GRP`.

## 3D-модели

Две сцены: секция трубы (`@google/model-viewer`) и раструбное соединение
в разрезе (чистый `three` с плоскостью отсечения).

Грабли, на которые уже наступили:

- **`gltf-transform optimize` ломает модель.** Он объединяет меши по материалу,
  и отдельные детали перестают анимироваться. Сжимать только через `draco`.
- Декодер Draco лежит локально в `public/draco/`. Тянуть его с gstatic нельзя —
  запрещено политикой CSP.
- Версия `three` прибита к 0.183: этого требует `@google/model-viewer`.
- Исходники моделей — в `assets-3d/`, в git не попадают (весят сотни мегабайт).

## Форма обратной связи

Заявки уходят через [Resend](https://resend.com). Настройка:

```bash
cp .env.local.example .env.local
```

и вписать `RESEND_API_KEY`. Пока ключа нет, форма честно пишет посетителю,
что отправка не настроена, — молча терять заявки она не будет.

Чтобы письма шли с адреса `@composite.tj`, домен надо подтвердить в Resend
DNS-записями.

## Безопасность

Заголовки и политика CSP собираются в `next.config.ts`.

`Strict-Transport-Security` и `upgrade-insecure-requests` включаются **только
в проде**. Если отдавать их по http, Safari запомнит обещание «этот адрес
всегда https» и перестанет открывать `http://localhost:3000`.

Карта Яндекса грузится только после согласия на cookie — см.
`src/components/cookie-consent.tsx` и `yandex-map.tsx`.
